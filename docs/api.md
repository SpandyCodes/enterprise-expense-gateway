# API

Full interactive documentation is auto-generated by FastAPI at
`/docs` (Swagger UI) and `/redoc` once the app is running, and the raw
OpenAPI schema at `/openapi.json`.

## Error format

All error responses use:

```json
{
  "error": {
    "code": "BAD_REQUEST",
    "message": "human-readable explanation",
    "correlation_id": "..."
  }
}
```

## Example calls

```bash
# Get a token
curl -s -X POST http://localhost:8000/auth/token \
  -H 'Content-Type: application/json' \
  -d '{"username": "EMP00001", "password": "Password123!"}'

# Create an expense report
curl -s -X POST http://localhost:8000/expense-reports \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"title": "Client visit", "currency": "USD"}'

# Ingest an external expense (idempotent)
curl -s -X POST http://localhost:8000/integrations/expenses \
  -H "Authorization: Bearer $SERVICE_TOKEN" \
  -H 'Idempotency-Key: 3f9c2b7e-...' \
  -H 'Content-Type: application/json' \
  -d '{
        "external_expense_id": "EXT-10001",
        "employee": {"employee_id": "EMP001"},
        "expense_type": "MEALS",
        "vendor": "Example Restaurant",
        "transaction_date": "2026-09-20",
        "amount": 1250.00,
        "currency": "INR",
        "receipt_reference": "receipt-10001"
      }'
```

Note: `PUT/DELETE /expense-items/{id}` and `PUT/DELETE
/expense-reports/{id}` are listed in the spec's route table but not yet
implemented in this scaffold (report/item mutation after creation) —
see the README "Limitations" section.
